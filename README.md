# Kinkeeper

The website for Kinkeeper, a phone app that helps adult children manage an aging parent's care: it reads letters, bills
and prescriptions, explains them in plain language and turns them into a to-do list, with everything kept on the phone.

Live at https://dalemagrath-developer.github.io/kinkeeper-site/ (French: `fr/`). A static page with no scripts, cookies,
analytics or web fonts. The waitlist is a Tally form, linked from the page.

Questions about your information: support.kinkeeper@gmail.com
